# 수집 범위와 제한

사용자가 확인한 범위는 **RAG·Langent 관련 작업 전체**입니다. 이 저장소는 접근 가능한 기존 기록을 모은 것이며, 접근하지 못한 자료를 복원하거나 새 작업 결과를 만들지 않았습니다.

## 로컬 Codex

- 첫 전수 검색 대상: `.codex/sessions`의 로그 583개
- 실제 user 메시지의 RAG·Langent·Ollama·Qwen3·Dify·벡터·임베딩 관련 후보: 19개 사용자 세션
- assistant 최종 응답을 대상으로 한 추가 검색 후보: 1개
- 보존: 15개 사용자 세션, 92개 user/assistant 메시지
- 승인 검토 세션, 시스템·환경 지시, 내부 추론, 관련 없는 앞부분의 대화는 보존 대상에서 제외
- 범용 온톨로지 팩 작업 4개와 별도 앱의 Ollama 변경 작업 1개는 RAG/Langent 직접 관련 근거가 부족하여 제외. 세션별 이유는 [manifest](../evidence/codex/manifest.json)에 기록

## ChatGPT

로그인된 계정의 전역 검색과 실제 대화 화면을 이용했습니다. 검색어는 `RAG`, `Langent`, `Ollama`, `Qwen3`, `01_vector_db`입니다. `Langent`와 `01_vector_db`의 완료된 검색 화면에는 결과가 없었습니다. 이를 계정 전체에 관련 기록이 없다는 의미로 확대하지 않았습니다.

관련 대화 본문 9개와 기존 SVG를 확인·보존했습니다. `RAG` 검색 결과에는 뉴스 브리핑·도서 분석·개인 체크인의 간접 언급도 있었으며, 직접적인 구축 기록으로 취급하지 않았습니다.

대화 본문은 접근성 스냅샷입니다. 일부 생성 UI의 표·코드·사용자 메시지·도구 실행 기록은 스냅샷에서 빠질 수 있습니다. 원문 대화 링크를 함께 보존했으며, 빠진 부분을 새로 작성하지 않았습니다. 삭제된 대화·다른 계정·다른 PC·접근 불가능한 세션을 전부 확인했다고 주장하지 않습니다.

## 추가 사이트 로그인 승인과 보존 결과

`남진 AI 자동화와 Graph RAG` 사이트의 초기 로그인 동작은 자동 승인 검토에서 거절되었습니다. 이후 사용자가 **사이트 로그인 허용**을 명시하여, 현재 ChatGPT 계정과 인증 계정이 일치함을 확인하고 정상 로그인 절차를 완료했습니다. 계정 설정이나 사이트 접근 범위는 변경하지 않았습니다.

로그인 후 실제 사이트 본문과 HTTP 200으로 받은 제공 HTML을 보존했습니다. 사이트는 스스로 학습·설계 단계이며 평가 수치를 아직 수집하지 않았다고 명시합니다. 웹사이트 제공 HTML을 원래 편집 가능한 개발 저장소의 완전한 내보내기 파일로 표현하지 않습니다. 인증 과정의 계정 이메일·쿠키·토큰은 보존하지 않았습니다.

## 파일 수집

기존 `01_vector_db` 체크아웃, 개인 Langent 플러그인, 기존 KNCCS 그래프 생성 파일, 설치본 코드 일부, 로컬 벡터 파일 및 기존 SVG를 보존했습니다. 원본 데이터와 버전을 바꾸지 않았으며, `.env`, 인증 저장소, API 키, 가상환경과 설치 패키지 전체는 보존 대상에 넣지 않았습니다.

로컬 런타임에는 Git 메타데이터가 없어 설치본의 원래 커밋은 확인하지 못했습니다. 파일별 SHA-256으로 수집한 코드를 식별합니다. 벡터 파일 사본의 SQLite 검사는 기록하되, 전체 서비스 복원·검색 품질·Neo4j 현재 연결 상태를 인증하지 않습니다. Neo4j 서버 저장소 자체의 백업은 포함하지 않았습니다.

## 확인 기준

수집 파일의 해시 일치, JSON 구문, 보관 SQLite 파일의 읽기 및 `quick_check`, 업로드 대상의 비밀 값 패턴·제외 경로, GitHub 등록 결과를 확인합니다. 이 확인을 사내 RAG의 기능·보안·환각 감소 검증으로 해석하지 않습니다.
