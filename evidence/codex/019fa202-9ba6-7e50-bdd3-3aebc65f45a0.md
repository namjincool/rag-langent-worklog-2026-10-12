`Langent MCP One-Click Kit`은 문서를 벡터 DB와 지식 그래프로 구축하고, RAG 검색·그래프 추론·에이전트 질의를 수행하는 통합 MCP입니다.

주요 기능:

- `langent_ingest`: 지정 폴더의 문서를 분석·인덱싱
- `langent_query`: 벡터 검색과 그래프 검색을 결합한 하이브리드 RAG
- `langent_chat`: LangGraph 에이전트가 검색 결과를 바탕으로 답변·추론
- `langent_graph`: Neo4j에 Cypher 쿼리 실행
- `langent_nebula`: 지식 관계를 3D 성운 형태로 시각화
- `langent_status`: DB 적재량과 그래프 연결 상태 확인

일반적인 사용 순서는 다음과 같습니다.

`문서 준비 → ingest → query 또는 chat → graph 분석 → nebula 시각화`
