`langent-mcp-one-click-kit`은 한마디로 **내 PC의 문서를 Langent 지식베이스로 인제스트하고, AI 도구가 MCP로 그 문서를 검색하게 해주는 Windows용 원클릭 키트**입니다.

할 수 있는 일은 크게 이렇습니다.

| 기능 | 설명 |
|---|---|
| 문서 인제스트 | `workspace` 폴더의 `.md`, `.txt`, `.pdf`, `.csv`, `.json`, `.yaml` 등을 읽어서 검색 가능한 벡터 DB로 변환 |
| 의미 기반 검색 | 단순 키워드가 아니라 비슷한 의미의 문서를 찾아주는 시맨틱 검색 |
| MCP 서버 실행 | Codex, Claude Desktop, Cursor, Antigravity 같은 AI 도구가 Langent 지식베이스를 사용할 수 있게 연결 |
| 3D 지식 지도 | 문서들을 3D “Nebula” 화면으로 시각화해서 비슷한 문서끼리 모여 보이게 함 |
| CLI 검색 | 터미널에서 `langent query "검색어"` 형태로 직접 검색 |
| 문서 관계 연결 | `langent link`로 문서 간 관계를 연결. Neo4j는 선택사항 |
| 상태 확인 | 설치 상태, workspace 파일 수, 패키지 상태 등을 확인 |
| 원클릭 설치/실행/삭제 | `INSTALL.bat`, `RUN.bat`, `UNINSTALL.bat`로 설치, 실행, 삭제를 쉽게 처리 |

현재 로컬 설정상 MCP 서버는 이렇게 연결되도록 되어 있습니다.


- “내 문서에서 AI 전략 관련 내용 찾아줘”
