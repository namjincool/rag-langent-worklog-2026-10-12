현재 `langent-mcp-one-click-kit` MCP는 연결되어 있고, 사용 가능한 도구는 아래 6개입니다.

- `langent_status`: 현재 상태 확인
- `langent_ingest`: 문서/코드 인덱싱
- `langent_query`: 벡터 DB + 그래프 기반 검색
- `langent_chat`: LangGraph 에이전트와 대화
- `langent_graph`: Neo4j Cypher 쿼리 실행
- `langent_nebula`: 3D 성운 시각화 데이터/경로 확인

방금 확인한 현재 상태는 이렇습니다.

```json
{
  "version": "3.0.0",
  "vector_count": 0,
  "graph_connected": false,
  "collections": ["langent_knowledge"]
}
```

즉, MCP 서버는 살아 있지만 아직 인덱싱된 문서가 없고, Neo4j 그래프는 연결되지 않은 상태입니다.

가장 기본적인 사용 흐름은 이겁니다.

```text
1. 상태 확인
   → langent_status

2. 현재 프로젝트나 문서 폴더 인덱싱
   → langent_ingest(path=".")

3. 검색
   → langent_query(query="LangGraph 설치 확인 코드 설명해줘", top_k=5)

4. 에이전트에게 질문
   → langent_chat(message="이 프로젝트 구조를 설명해줘")

5. 그래프 DB가 연결된 경우 Cypher 실행
   → langent_graph(cypher="MATCH (n) RETURN n LIMIT 10")
```

Codex에서는 직접 함수명을 치기보다는 이렇게 요청하면 됩니다.

```text
이 프로젝트를 Langent로 인덱싱해줘
```

```text
Langent에서 "LangGraph 설치 확인" 관련 내용을 검색해줘
```

```text
Langent 에이전트로 현재 코드 구조를 설명해줘
```

지금 바로 시작하려면 제가 다음으로 이 워크스페이스를 인덱싱하면 됩니다. 다만 현재 MCP의 workspace가 `CreatorTemp\langent-mcp-one-click-kit-runtime\workspace`로 잡혀 있어서, 이 프로젝트 경로를 대상으로 넣어 인덱싱하는 방식으로 진행하면 됩니다.
